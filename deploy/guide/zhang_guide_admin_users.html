用户管理

后台用户管理页面，查看注册用户列表，支持搜索、分页、编辑资料、重置密码与删除用户。

用户管理 权限 增删改查

页面说明

用户列表展示用户名、昵称、邮箱与注册时间，支持按用户名或邮箱搜索；编辑弹窗可修改昵称与邮箱，并可重置密码。

删除用户需要二次确认，避免误删；所有操作都经过管理员令牌校验，未登录时会自动跳回登录页。

功能要点

  • 按用户名 / 邮箱搜索
  • 分页浏览与总数展示
  • 编辑用户资料
  • 重置用户密码
  • 删除用户二次确认

接口说明

方法接口路径说明
GET /api/admin/users 分页查询注册用户列表
POST /api/admin/users 新增用户
GET /api/admin/users/:id 查询用户详情
PUT /api/admin/users/:id 修改用户资料或重置密码
DELETE /api/admin/users/:id 删除用户
