前台功能 · 01

数据库连接

输入 MySQL 账号与密码发起连接，页面展示连接结果，并列出当前数据库名、主机与服务器版本等连接信息。

MySQL Express 表单校验

页面说明

页面用于验证后端数据库配置是否可用。提交表单后，Express 使用请求中的账号密码尝试建立 MySQL 连接，前端把返回的连接信息渲染成键值列表，并将完整 JSON 响应打印到浏览器控制台。

连接失败时页面保留红色错误提示，便于排查账号、密码或数据库名；连接成功时展示服务器版本与当前连接数，帮助确认数据库服务状态。

功能要点

  • 表单校验：账号、密码、数据库名不能为空
  • 状态反馈：成功与失败使用不同颜色的提示条
  • 信息展示：数据库名、主机、端口、版本与连接数
  • 控制台输出：完整接口 JSON 响应
  • 仅使用原生 JavaScript 操作 DOM，无第三方依赖

接口说明

方法接口路径说明
POST /api/db/connect 使用提交的账号密码连接 MySQL 并返回连接信息
