管理后台 · 01

管理仪表盘

后台首页仪表盘，汇总新闻、农产品与注册用户数量，并用图表展示近 30 天数据变化。

仪表盘 统计图表 管理后台

页面说明

仪表盘顶部是三类实体的总量统计卡，下方使用 Canvas / ECharts 图表展示近期新闻发布与用户注册趋势。

所有数据来自后台统计接口，页面在加载时统一请求并渲染，请求失败时显示错误提示而不是空白区域。

功能要点

  • 新闻、农产品、用户总量统计
  • 近 30 天趋势图表
  • 加载过程骨架 / 提示
  • 数字滚动动画
  • 接口异常提示

接口说明

方法接口路径说明
GET /api/admin/dashboard 获取后台统计数量与趋势数据
