管理入口 · 11

管理员登录

管理员使用账号、密码与图形验证码登录后台，成功后返回 2 小时有效的 JWT 令牌并进入管理后台。

管理员 JWT 登录鉴权

页面说明

管理员登录与普通用户登录相互独立，接口会校验管理员表中的账号与 scrypt 密码哈希，并签发带 role 为 admin 的令牌。

登录成功后令牌与管理员信息写入 localStorage，后台布局脚本在每次进入页面时检查登录态，缺失时跳回登录页。

功能要点

  • 管理员账号密码与图形验证码校验
  • JWT 令牌有效期 2 小时
  • 登录态写入 localStorage
  • 未登录访问后台自动跳转登录页
  • 登录失败原因提示

接口说明

方法接口路径说明
GET /api/auth/captcha 获取图形验证码与验证码编号
POST /api/admin/login 管理员登录并返回令牌与管理员信息
GET /api/admin/me 获取当前登录管理员信息
