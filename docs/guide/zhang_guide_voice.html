语音识别

上传或录制语音文件，调用语音识别接口转写为文字，支持语言选择与历史记录查看。

语音识别 ASR 意图识别

页面说明

页面支持选择音频文件并试听，提交后由后端调用语音识别接口输文字结果，同时给出客服意图识别结果。

历史记录按时间倒序展示，便于回看最近的转写内容；语言下拉列表从后端动态获取。

功能要点

  • 音频文件选择与本地试听
  • 语种下拉列表动态加载
  • 转写结果与意图识别展示
  • 历史记录查询
  • 上传格式与大小校验

接口说明

方法接口路径说明
POST /api/voice/transcribe 上传音频并返回转写文本与意图识别结果
GET /api/voice/history 查询语音识别历史记录
GET /api/voice/languages 获取支持的语种列表
